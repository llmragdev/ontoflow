# 로드맵

이 문서는 OntoFlow를 어떤 순서로 구현할지 설명합니다.

`Core-1`, `Core-2` 같은 이름은 내부 개발 단계 식별자입니다. 일반 제품 버전명이 아니라, 어떤 기반 기능을 먼저 만들고 그 위에 어떤 기능을 얹을지 표시하기 위한 작업 단위입니다.

## 2026년 코어 범위

2026년의 목표는 **Workflow Manager**와 **Ontology Manager**를 실무 적용 수준으로 만드는 것입니다. 대화식 입력, Gate, 자동 실행은 코어 위에 붙는 확장 컴포넌트로 다룹니다.

## 구현 순서

| 단계 | 만드는 것 | 왜 먼저 필요한가 |
|---|---|---|
| Core-1 | 타입 기준 기본 구조 | 업무 객체, 속성, 관계, 액션의 기준이 있어야 이후 검증과 실행이 가능하다 |
| Core-2 | 영속 지식 저장소와 Apply 경계 | 실제 업무 데이터와 변경 이력을 저장하고, 모든 쓰기 경로를 한 통로로 모은다 |
| Core-3 | Unified Validator 최소 규칙셋 | 입력, 일괄 등록, 직접 편집, 워크플로우 결과가 같은 기준으로 검증되게 한다 |
| Core-4 | 일괄 등록과 사전 점검 | 파일·API로 들어오는 많은 데이터를 검증하고 적용할 수 있게 한다 |
| Core-5 | 타입 변경 제안과 승인 | 업무 기준 자체를 바꾸는 변경은 영향 분석과 승인 절차를 거치게 한다 |
| Core-6 | 워크플로우 정의 구조 | 업무 절차, 역할, 노드, 제어 흐름을 저장할 수 있게 한다 |
| Core-7 | 슬롯 선언과 액션 연결 | 각 노드가 어떤 값을 읽고 쓰며 어떤 작업을 호출하는지 정적으로 검사한다 |
| Core-8 | 워크플로우 실행 상태 | 실행 중 역할 바인딩, 상태 슬롯, 단계 진행 상태를 관리한다 |
| Core-9 | 상태 이력과 실행 근거 | 값이 언제, 어느 단계에서, 어떤 외부 호출로 바뀌었는지 추적한다 |
| Core-10 | 버튼/폼 실행과 리포트 | 사용자가 버튼이나 폼으로 업무를 실행하고, 실행 전 점검 결과를 확인한다 |

## 낯선 용어 풀이

| 용어 | 뜻 |
|---|---|
| 타입 기준 | 업무 객체의 클래스 타입, 속성, 관계, 액션 정의 |
| 영속 지식 | 실제 저장되는 업무 데이터. 객체 인스턴스, 속성값, 관계, 변경 이력 포함 |
| Apply 경계 | 실제 업무 데이터를 바꾸는 공통 반영 통로 |
| Unified Validator | 모든 입력과 쓰기를 같은 기준으로 검사하는 공통 검증기 |
| ImportJob | 파일이나 API로 들어온 대량 데이터를 검증하고 반영하는 작업 단위 |
| ImportItem | ImportJob 안의 개별 항목. 한 줄 데이터 또는 한 개 변경 항목 |
| ABox 일괄 적재 | 실제 업무 데이터 인스턴스를 여러 건 한꺼번에 등록하는 작업 |
| TBox 변경 | 업무 객체 타입, 속성, 관계 같은 기준 정의를 바꾸는 작업 |
| dry-run | 실제 반영 없이 미리 검증하고 예상 결과를 보는 모드 |
| State Slot | 워크플로우 실행 중 임시로 보관하는 이름 있는 값 |

## 확장 컴포넌트

확장 컴포넌트는 코어가 동작한 뒤 앞이나 뒤에 조립하는 기능입니다. 코어 기능의 일부가 아니라, 같은 계약을 사용하는 추가 모듈입니다.

| 단계 | 만드는 것 | 설명 |
|---|---|---|
| Conv-P1 | 의도 인식, 세션, 후보 버퍼 | 사용자의 말을 실행 후보와 입력값 후보로 바꾼다 |
| Conv-P2 | 되묻기, 정규화, 신뢰도 | 빠진 값을 되묻고 표현을 기준 용어로 맞춘다 |
| Conv-P3 | 발화 근거와 실행 제안 | 어떤 말에서 어떤 값이 나왔는지 기록하고 실행을 제안한다 |
| Gate-P1 | 변경 후보 저장 | 워크플로우 결과를 바로 반영하지 않고 승인 후보로 보관한다 |
| Gate-P2 | 최소 승인 화면 | 이전값, 후보값, 근거를 보고 승인 또는 반려한다 |
| Gate-P3 | WriteBack 모의 흐름 | 외부 시스템 반영 흐름을 실제 쓰기 전에 검증한다 |

## 후속 범위

- 자동 실행

- 도메인별 템플릿
