# 로드맵

## 2026년 코어

| 단계 | 범위 |
|---|---|
| Core-1 | 타입 정본 기본 구조 |
| Core-2 | 영속 지식 저장소와 Apply 경계 |
| Core-3 | Unified Validator 최소 규칙셋 |
| Core-4 | ImportJob, ImportItem, ABox 일괄 적재, dry-run |
| Core-5 | TBox 변경 제안, 영향 분석, 승인 |
| Core-6 | 워크플로우 정의, 역할, 노드, 제어 선 |
| Core-7 | 슬롯 선언, 액션 바인딩, 정적 검사 |
| Core-8 | 워크플로우 실행, 역할 바인딩, 상태 슬롯 |
| Core-9 | 상태 슬롯 이력, 액션 로그, 근거 |
| Core-10 | 버튼/폼 실행과 dry-run 리포트 |
