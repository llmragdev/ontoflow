# Ontology Manager

Ontology Manager는 업무에서 다루는 객체, 속성, 관계와 실제 데이터를 관리하는 컴포넌트입니다.

## 1. 목표

```text
업무 객체 유형을 정의한다.
속성과 관계의 기준을 관리한다.
실제 업무 데이터를 등록하고 갱신한다.
일괄 등록 데이터를 검증한다.
값 변경 이력을 추적한다.
워크플로우가 같은 기준으로 데이터를 읽고 쓰게 한다.
```

## 2. 다루는 데이터

| 구분 | 쉬운 표현 | 예시 |
|---|---|---|
| Object Type | 업무 객체 유형 | 환자, 의사, 예약, 설비 |
| Property | 속성 | 이름, 상태, 예약일, 우선순위 |
| Relation | 관계 | 환자가 예약을 가진다, 예약이 의사와 연결된다 |
| Object Instance | 실제 업무 객체 | 특정 환자, 특정 예약 |
| Property Value | 실제 속성값 | 예약 상태가 확정 |
| Relation Instance | 실제 관계 | 예약 A가 의사 B와 연결됨 |

## 3. 일괄 등록

실제 업무에서는 파일이나 API로 많은 객체를 한 번에 등록해야 합니다.

Ontology Manager는 일괄 등록 시 다음을 확인합니다.

```text
필수 속성이 있는가
값의 형식이 맞는가
허용된 관계인가
중복 객체가 있는가
일부 실패를 어떻게 처리할 것인가
적용 후 이력을 남겼는가
```

## 4. 워크플로우와의 연결

워크플로우는 Ontology Manager가 관리하는 업무 객체를 읽고 씁니다.

예를 들어 예약 워크플로우는 환자 객체를 찾고, 예약 후보를 만들고, 외부 예약 API 결과를 예약 객체 상태로 반영합니다.

이때 어떤 단계가 어떤 객체의 어떤 값을 바꿨는지 기록되어야 합니다.
