# Governance

[한국어](GOVERNANCE.md) | English

OntoFlow welcomes public contribution. The official repository, documentation direction, and release criteria are managed by the project lead.

## Principles

```text
Contributions are publicly credited.
The official repository, documentation direction, and release criteria are managed by the project lead.
Contributor credit does not imply project representative authority or repository administration rights.
Unless separately agreed, private lab access and public repository administration are separate.
```

## Participant Roles

| Role | Meaning |
|---|---|
| Public Contributor | Someone who participates through Issues, Discussions, PRs, or documentation improvements |
| Early Contributor | Someone who makes meaningful early design, review, or outreach contributions |
| Core Contributor | Someone invited to the private lab after repeated and verifiable contribution |
| Project Lead | The steward of the official repository, documentation direction, and release criteria |

## Credit

Contributors may be credited in README files, contributor lists, release notes, presentations, or other project materials.

Credit does not automatically create:

```text
official repository administration rights
official release decision rights
project representative authority
private lab access
final decision rights
```

## Licensing

This repository currently focuses on design documents and examples.

| Area | Default Direction |
|---|---|
| Documents | Open for public review. Final license is under review |
| Examples | Public synthetic examples. Final license is under review |
| Core source | Non-commercial source-available direction under review |
| Production code | To be decided before code publication |

Contributions submitted to the public repository may be used under the contribution policy and the license terms confirmed later.

See [LICENSE-POLICY.md](LICENSE-POLICY.md) for the current policy note.

## Private Lab

`ontoflow-lab` is a private workspace for drafts, deeper review, and release preparation.

Private lab access is an invite-based trust permission. It does not automatically grant public repository administration rights or final release authority.

## Legal Note

This document describes project operating principles. Licensing, contributor agreements, and external collaboration terms should be reviewed before code contribution begins.
